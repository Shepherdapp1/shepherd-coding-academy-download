Get started in three steps
Download the installer using the link above. It saves as
Shepherd-Coding-Academy-Setup.exe.
Run it. It installs into your own user folder, so no administrator password
is needed.
Open Shepherd Coding Academy and choose a course. Lessons are stored on your
device and stay readable with no internet connection.
Windows may show a warning
The app is a small independent project, not a company with a paid Microsoft
certificate. Windows SmartScreen may therefore say "Windows protected your PC".

Click More info, then Run anyway.
Every release is built automatically from the source repository, and each one
ships a signed update file so installed copies can verify what they download.
What is inside
Courses you download once. Each course arrives as a complete package: lessons,
examples, quizzes and exercises. Nothing streams, so nothing stops working when
the connection does.
A real compiler, when a course needs one. C++ courses offer their compiler as a
separate download beside the course. It is large, so it is fetched only if you
choose a course that uses it, and it is kept on your device between app updates.
Your progress and settings stay on your device. A local database, no cloud, no
sign-in, no telemetry.
A built-in updater that never touches your lessons. When the app updates, your
courses, downloaded compiler and preferences are left exactly where they are.

optional. If you skip one, your lessons are unaffected.

Questions
Do I need internet? Only to download the app, a course, or a compiler for the
first time. After that, everything works offline.
Is there an account? No. The app never asks who you are.
Where is my work kept? In your own user folder, under
%LOCALAPPDATA%\Shepherd Coding Academy. Uninstalling the app does not delete it
unless you ask it to.
Which Windows versions? Windows 10 version 1809 or newer, and Windows 11, both
64-bit.
Will it run on a Mac or a phone? Not yet. This release is Windows only.
