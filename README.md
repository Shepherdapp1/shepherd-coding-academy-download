Get started in three steps
Download the installer using the link above. It saves as
Shepherd-Coding-Academy-Setup.exe.
Run it. It installs into your own user folder, so no administrator password
is needed.
Open Shepherd Coding Academy and choose a course. Lessons are stored on your
device and stay readable with no internet connection.
Windows may show a warning
This app is a small independent project, not a company with a paid Microsoft
certificate. Two different warnings can appear, and both are expected. Nothing is
wrong with your download.

Your browser says the file isn't commonly downloaded

Find Shepherd-Coding-Academy-Setup.exe.
Click the three dots beside it, then Keep.

Your first five minutes
The app installs on its own. Courses do not. A new installation starts with an
empty library, and that is expected — not a fault.

Open Subjects & languages in the left sidebar.
Press Check for courses.
Press Download beside the course you want. It arrives complete: lessons,
examples, quizzes and exercises, stored on your device.
Choose a C++ course? Its page then offers Install compiler. That is a
one-time download of about 250 MB, and it is kept on your device across app
updates.
Open the course and read from its first lesson. The MAP strip on the left
opens the full list of lessons — if you are new to the language, start at the top
of that list rather than wherever the course page happens to open.
Once a course is downloaded, it never needs the internet again.

Running your first program
Under each example there is Run example. Beneath it, a YOUR TURN card gives
you the same task on an empty editor, with Run my code and a hint you can
reveal when you want it.
Output and compiler messages appear below the editor, so a mistake in your code
reads as a message, not as a mystery.
Longer explanations offer Go deeper and The detail, so a page can be read
quickly or in full.
If something looks wrong
Settings → Copy diagnostics copies the app version, the files it is running
and the end of its log to your clipboard. Paste that into a message with a short
description of the problem — it turns "it does not work" into something fixable.

You can install again over an existing copy at any time. Your courses, compiler
and settings are left untouched.

What is inside
Courses you download once. Each course arrives as a complete package: lessons,
examples, quizzes and exercises. Nothing streams, so nothing stops working when
the connection does.
A real compiler, when a course needs one. C++ courses offer their compiler as a
separate download beside the course. It is large, so it is fetched only if you
choose a course that uses it, and it is kept on your device between app updates.
Your progress and settings stay on your device. A local database, no cloud, no
sign-in, no telemetry.
A built-in updater that never touches your lessons. When the app updates, your
courses, downloaded compiler and preferences are left exactly where they are.

Questions
Do I need internet? Only to download the app, a course, or a compiler for the
first time. After that, everything works offline.

Is there an account? No. The app never asks who you are.

Where is my work kept? In your own user folder, under
%LOCALAPPDATA%\Shepherd Coding Academy. Uninstalling the app does not delete it
unless you ask it to.

Which Windows versions? Windows 10 version 1809 or newer, and Windows 11, both
64-bit.

Will it run on a Mac or a phone? Not yet. This release is Windows only.
